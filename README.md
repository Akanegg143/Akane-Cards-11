# Akane-Cards-11

Card image storage for card-bot. Images are organised into
`Permanent-N` / `3D-N` / `Summer2026-N` / `Wedding2026-N` / `Halloween2026-N` / `Poster-N` / `Halloween-poster-N` folders, capped at 50 files each.
This repo holds up to 500 card images before the bot rotates to the next one.
